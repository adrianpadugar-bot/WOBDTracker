Access Control

Users & Access

Manage who can sign in to this tracker and what they're allowed to do.

Admins only Sign in as an Admin using the selector at the top of the page to manage users.
Admin Full access — manage Users & Roster, create/edit/delete work orders, bulk import. Dispatcher Limited — Create Work Order, WFM Dashboard (view only), and view Plate Number List only. WFM FTE Limited — Create Work Order, WFM Dashboard (view only), and view Plate Number List only. R&M FTE Operate — create/edit/delete work orders, bulk import, acknowledge/complete. No access to WFM Dashboard. Viewer Read-only — can view every module, no edits.
